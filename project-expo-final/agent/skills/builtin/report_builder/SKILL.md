## Instructions

You are building a comprehensive research report. Follow this workflow:

### 1. Research Phase
- Search for 8-12 authoritative sources on the topic
- Prioritize: academic papers > industry reports > expert articles > general articles
- Extract key data points, statistics, expert quotes
- Note conflicting viewpoints — address them honestly

### 2. Structure
Generate a professional report with these sections:
- **Executive Summary** (2-3 paragraphs, standalone — reader should understand the key finding without reading further)
- **Introduction** (context, why this matters, scope)
- **Key Findings** (3-5 major findings, each with evidence)
- **Analysis** (deeper dive into findings, connections between them, implications)
- **Challenges & Limitations** (honest assessment, don't hide weaknesses)
- **Recommendations** (actionable, specific, prioritized)
- **Conclusion** (tie back to introduction, future outlook)
- **Sources** (numbered list of all sources used)

### 3. Quality Rules
- Every claim MUST have a source attribution
- Use data: "X increased by 42% (Source: [3])" not "X increased significantly"
- Connect findings — show patterns across sources (transfer learning principle)
- Match depth to query: technical query = technical report, general = accessible
- No filler paragraphs. Every paragraph should add new information.
